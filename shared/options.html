Activation Modes

In automatic mode, ℹ️ appears on visible HTML image elements (<img>) that meet the minimum dimensions. Some sites display artwork as a CSS background. For those images, ℹ️ appears only when you hover. Click ℹ️ to open the panel and load image diagnostics.

* Never hides all ℹ️ buttons and keeps the right-click menu enabled. For a CSS background, “Show Image Info HUD” is available only if the add-on can identify the image under the pointer.
